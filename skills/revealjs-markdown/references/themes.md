# Theme palettes

Layout, components, and spacing live in [theme.css](theme.css). Each option below only changes **color** and **Latin typography**. Arabic/Quran lines keep Amiri (`--arabic-font`).

| ID | Name | Headings / body | Field · divider · accent | Best for |
|----|------|-----------------|--------------------------|----------|
| `amiri-teal` | Amiri Teal | Amiri / DM Sans | cream · teal · gold | Default; lecture decks in this house style |
| `naskhi-slate` | Naskhi Slate | Cormorant Garamond / Outfit | cool paper · slate · copper | Methodology, cooler academic tone |
| `diwan-burgundy` | Diwan Burgundy | Fraunces / Nunito Sans | warm paper · wine · saffron | Ceremonial or biographical decks |
| `mishkah-indigo` | Mishkah Indigo | Literata / Source Sans 3 | ivory · indigo · brass | Dense decks (quotes, footnotes, classification cards) |

CSS files: `themes/amiri-teal.css`, `themes/naskhi-slate.css`, `themes/diwan-burgundy.css`, `themes/mishkah-indigo.css`.
